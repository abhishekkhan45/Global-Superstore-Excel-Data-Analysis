# Global Superstore 2016 — Excel Dashboard

## 📊 Project Overview

This project is an **Excel-based Data Analytics and Business Intelligence dashboard** created using the **Global Superstore 2016 dataset**.

The project analyzes sales, revenue, profit, customers, products, regions, markets, discounts, shipping, and order performance. The analysis is presented through an interactive Excel dashboard to convert raw business data into meaningful insights.

## 📁 Dataset

The workbook contains the following sheets:

* **Orders** — Main dataset containing order, customer, product, sales, revenue, profit, shipping, and regional information.
* **Returns** — Information about returned orders.
* **People** — Regional/person-related information.
* **analyst** — Supporting analysis and calculations.
* **Dashboard** — Interactive dashboard for business performance analysis.
